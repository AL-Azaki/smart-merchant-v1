## تنظيم الوثائق

لكل موضوع مرجع واحد أعلاه. تعريفات الجداول والحقول والتعدادات في المصدر البرمجي؛ لا نكررها في ملفات استخراج يدوية. عند تغيير سلوك، يُحدّث مرجعه الموجود بدلاً من إنشاء تقرير إغلاق أو تقييم ذاتي جديد.

حُذفت تقارير المراحل والخطط ونسخ المخطط المتكررة بعد دمج المعلومات الحالية. تاريخ الملفات المتتبعة متاح في Git. ملفات نتائج التشغيل المؤقتة مكانها مجلد البناء، وليست وثائق مرجعية.

هذه الوثائق تصف النسخة الموجودة في المستودع وقت المراجعة. نجاح اختبارات نطاق معين لا يعني اكتمال كل الوحدات أو اعتماد النظام للإنتاج.
