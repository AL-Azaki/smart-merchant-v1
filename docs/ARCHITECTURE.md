# بنية المشروع

آخر مراجعة: 18 أكتوبر 2026. [الفهرس](../README.md).

## توزيع المسؤوليات

التطبيق المحلي مصدر العمليات اليومية للمخزون والبيع والمحاسبة. Laravel يدير الهوية والجلسات والأجهزة ويعرض بيانات الكتالوج والمخزون المنشورة ويستقبل الطلبات الإلكترونية. هذا الفصل لا يعني أن المزامنة تشمل كل الجداول؛ نطاقها الفعلي في [عقد المزامنة](SYNCHRONIZATION.md).

| المسار | المسؤولية |
|---|---|
| [lib/modules](../smart_merchant_erp/lib/modules) | الوحدات وواجهاتها وخدماتها ومستودعاتها |
| [lib/app](../smart_merchant_erp/lib/app) | إعداد التطبيق والاتصال والحقن والتنقل |
| [lib/kernel](../smart_merchant_erp/lib/kernel) | سياق التشغيل والتخزين والأمان والمزامنة |
| [lib/database](../smart_merchant_erp/lib/database) | الجداول والمحولات والاستعلامات والتهيئة |
| [lib/shared](../smart_merchant_erp/lib/shared) | التصميم والنماذج والمستندات المشتركة |
| [app/Services](../smart_merchant_platform/app/Services) | خدمات Laravel للجلسة والمزامنة والمتجر |

## مسار العملية

المسار المعتاد: واجهة ← مزود Riverpod ← خدمة تطبيق أو حالة استخدام ← مستودع/DAO ← SQLite. توجد استعلامات قراءة يستخدمها المزود مباشرة؛ هذا وصف للبنية الحالية، وليس ادعاء أن كل الملفات تطبق طبقات متماثلة.

تدار الاعتماديات عبر GetIt، وتشمل التسجيلات [manual_injection.dart](../smart_merchant_erp/lib/app/di/manual_injection.dart). `SessionNotifier` يعكس المنشأة والفرع والمستخدم في `SessionHolder` ليقرأها سياق العمليات. يجب مراجعة نطاق المنشأة والفرع في كل مسار؛ وجود السياق لا يضمن تطبيق العزل تلقائياً على كل استعلام.

## قواعد الصيانة

- تنفذ العمليات المترابطة في معاملة واحدة، وتبقى قواعد الكميات والقيود في طبقة الأعمال.
- الكميات المخزنية تطبع إلى وحدة المنتج الأساسية؛ تحفظ القيم المالية التشغيلية بعملة الأساس وفق مسار العملية.
- تثبت التغييرات في تعريفات الجداول الأصلية ثم تولد ملفات Drift، مع ترقية صريحة عند تغيير المخطط.
- يعاد استخدام نظام التصميم والمكونات المشتركة، مع دعم العربية والتابلت وحالات التحميل والخطأ وعدم وجود بيانات.
- وجود DAO أو جدول للموارد البشرية والأصول مثلاً لا يثبت اكتمال واجهاته ودورة تشغيله. يرجع التحقق إلى اختبارات وسلوك الوحدة.

لا يُعتمد على تقارير الإغلاق القديمة أو نسب اكتمال المراحل لتقرير الجاهزية. المرجع الحالي هو المصدر والاختبارات و[الحالة الحالية](STATUS.md).
