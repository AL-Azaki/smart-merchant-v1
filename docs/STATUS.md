# الحالة الحالية وأولويات المراجعة

آخر مراجعة: 18 أكتوبر 2026. [الفهرس](../README.md). هذه قائمة حالة مبنية على المصدر وأدلة نطاقات محددة، وليست شهادة اكتمال النظام.

## نطاق تحقق حديثاً

تحسين قائمة المنتجات ونموذجها، وشجرة الحسابات وإضافة الحساب، وتجميع صفحات المخزن والجرد. اكتملت دورة الجرد التصحيحي بالحساب المؤقت والمعالجة اللاحقة، مع تصحيح أرصدة التحويلات وحماية المدخلات وإضافة ترقية SQLite إلى النسخة 6. التفاصيل في [الجرد](INVENTORY.md) و[الحسابات](ACCOUNTING.md).

نجح آخر نطاق موثق للمخزن والمنتجات في 67 اختباراً، ثم أعيدت 16 حالة للنواة بعد تعديل المعاملة الخاصة بالترقية، ونجح بناء Android التجريبي لمعمارية arm64. هذا لا يغطي تلقائياً تغييرات متزامنة أو لاحقة في البيع والطباعة وغيرها. [أدلة وأوامر التحقق](TESTING.md).

## أولويات قبل وصف النظام بالجاهز للإطلاق

| الموضوع | الحالة المطلوبة |
|---|---|
| المزامنة | معالجة فجوات تحديث الحقول والصور ومؤشر الطلبات وديمومة الطابور؛ الأدلة في [العقد](SYNCHRONIZATION.md) |
| الدخول التجريبي | مراجعة `loginAsDemo` واستدعاءاته من الواجهة؛ علم بيئة الاختبار لا يحكم هذا المسار المباشر حالياً |
| البيانات السابقة | مراجعة الحسابات القديمة المرتبطة بقيود؛ لم تحذف ضمن تحسين الواجهة |
| الضرائب | في `PosCartItem` و`addItem` في مزود نقطة البيع قيمة افتراضية `0.15`؛ يلزم تدقيق تطبيق إعدادات ضرائب المنتجات على كل مسارات البيع |
| إيقاف البيع واستعادته | مراجعة بقاء السلة بعد إعادة التشغيل؛ لا نفترض أن بقاء حالة Riverpod في الذاكرة يمثل حفظاً دائماً |
| أرصدة الافتتاح | تدقيق المسارات القديمة مالياً مستقلاً؛ لا نفترض أنها تطبق دورة الجرد التصحيحي الجديدة |
| النسخ الاحتياطي والاستعادة | إثبات استعادة قاعدة فعلية بنجاح؛ مزامنة الكتالوج لا تقوم مقام نسخة كاملة |
| الطباعة والإعدادات | التحقق من بيانات المنشأة والعربية والورق والطابعة الفعلية، مع إعادة التحقق بعد التغييرات الجارية |
| دورة تشغيل كاملة | اختبار شراء وبيع ومرتجع وقبض وصرف وإقفال وصلاحيات وفروع على بيانات واقعية منفصلة، ثم مطابقة المخزون ودفتر الأستاذ |

المراجع المباشرة: [AuthNotifier](../smart_merchant_erp/lib/modules/authentication/presentation/providers/auth_provider.dart)، و[مزود نقطة البيع](../smart_merchant_erp/lib/modules/sales/presentation/providers/pos_provider.dart). البنود التي تتطلب التحقق ليست حكماً بأن كل ميزة مفقودة؛ لا تُحوّل إلى مهام تنفيذ قبل فحص النسخة الحالية.
