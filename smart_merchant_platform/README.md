# خادم التاجر الذكي

خادم Laravel للمصادقة وتهيئة الجلسة والأجهزة وإدارة المنشآت والمتجر والمزامنة. متطلبات النسخة الحالية: PHP `^8.3` وLaravel `^13.8` وفق [composer.json](composer.json). راجع [فهرس المشروع](../README.md) و[عقد المزامنة](../docs/SYNCHRONIZATION.md).

## الإعداد المحلي

من هذا المجلد:

```sh
composer install
```

أنشئ ملف `.env` من `.env.example` إن لم يكن موجوداً، ثم اضبط اتصال قاعدة تطوير منفصلة. بعض الخدمات والترحيلات تستخدم خصائص PostgreSQL؛ إعداد SQLite الافتراضي في القالب لا يثبت توافق التطبيق معه.

```sh
php artisan key:generate
php artisan migrate
php artisan serve
```

نفذ توليد المفتاح مرة عند التهيئة، ولا تستبدل مفتاح بيئة موجودة. تطبيق الترحيلات يحتاج قاعدة البيانات المقصودة والمجهزة مسبقاً. هذه أوامر إعداد موثقة، ولم تُنفذ على قاعدة المستخدم ضمن مراجعة الوثائق.

## نقاط الدخول

المصدر التفصيلي هو [routes/api.php](routes/api.php):

- `/api/auth`: تسجيل ودخول وهوية المستخدم وخروج.
- `/api/business/setup` و`/api/session/bootstrap` و`/api/devices/register`: إعداد التشغيل والجلسة والجهاز.
- `/api/sync/push` و`/api/sync/pull` و`/api/sync/ack`: بوابة المزامنة.
- `/api/storefront/v1/{store}`: قراءة المتجر والأصناف واستقبال الطلبات.
- `/api/admin/v1`: واجهات الإدارة المحمية؛ الصلاحيات في الوسطاء والمتحكمات، ولا يغني وجود Sanctum وحده عن عزل المنشآت.

بادئة `/api/platform` موجودة دون مسارات عمليات داخل مجموعتها حالياً. وجود مسار أو اختبار لا يعني اكتمال الميزة؛ حدود التنفيذ في [الحالة الحالية](../docs/STATUS.md).

## الاختبارات

```sh
php artisan test
```

جهز قاعدة اختبار مستقلة وراجع [phpunit.xml](phpunit.xml) أولاً: اتصال قاعدة البيانات ليس مضبوطاً فيه إلى SQLite داخل الذاكرة. لا تشغّل اختبارات تعدل البيانات على قاعدة تشغيل فعلية. لم تُعد اختبارات Laravel خلال تنظيف الوثائق.
